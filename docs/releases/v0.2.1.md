*veles 0.2.1, 2026-11-08.*

A hotfix release.

## Fixes

- **Translate selection result is now visible.** The popup showed only
  the source text and a "Translation result" label; the result pane was
  created but never added to the layout. Copy worked because the text
  widget existed, but the translation was invisible.

## Upgrading

- Run the installer again on Linux or Windows, or install the new APKs
  over the old ones on Android (userland first). The Android version code
  is 8; the APKs keep the existing release certificate. Configuration and
  transcripts are preserved. Restart the gateway and reload the desktop.
