The first public release of veles, a personal AI agent with a terminal
UI, a Tcl/Tk desktop app, Telegram and IRC gateways, and an Android app.
It works with OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, a
local Ollama, or any OpenAI-compatible server.

## Getting started

Install (below), then run `veles setup` in a terminal or `veles gui` for
the desktop. The setup wizard asks for a provider, takes the API key into
an encrypted vault, and lists the provider's models to pick from.
`veles doctor` checks the install. Documentation:
<https://veles-docs.7778777.online/>.

## Platforms

| platform | artifact |
|---|---|
| Linux x86_64 | `install.sh` (archive) or the AppImage |
| Windows 10/11 x64 | `install.ps1` or the portable zip |
| Android 8+ (arm64) | the veles and userland APKs; install the userland first |
| Linux arm64 | best effort: attached when that build finished |
| NixOS | the flake (`nixosModules.default`) |

## Known limitations

- Not on any app store or package repository yet; Android is sideload
  only.
- macOS is not supported.
- No container image is published; the container-host install profile
  needs an image you name.
- Racket and Lisp plugin hosts are not built on Windows.
- On Windows, `veles install profile` previews the desktop profile but
  cannot apply it yet.
- The PDS and media host components have run on test machines but not
  yet against a real public domain (certificate issuance, PDS
  activation).
- The documentation's translated pages can lag behind the English ones.
